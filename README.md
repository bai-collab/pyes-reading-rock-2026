# 北園國小閱讀素養課程導航

靜態網站版，目的是把 Google Sheet 中分散的資料轉為教師可快速理解的關聯式閱讀介面。

## 首頁邏輯

以「課程總圖」為出發點：

`年級 → 閱讀角色 → 核心閱讀能力 → 課程 → 核心書／搭配文本 → 閱讀策略 → 學生任務／作品 → 閱讀磐石指標`

## 網站頁面

- 課程總圖：六年縱向閱讀進程與各年級完整關聯
- 閱讀策略：對應「閱讀策略×課程領域雙向表」
- 16項指標：對應閱讀磐石五大面向與16項子指標
- 執行進度：將甘特圖轉為教師易讀時間線

## GitHub Pages

此專案為純靜態 HTML/CSS/JS，不需建置工具。Repository 建立後，可直接使用 GitHub Pages 從 `main` branch root 發布。

## 資料原則

- 「候選核心文本」保留教師討論空間。
- 「核心書／搭配文本」為目前建議組合，不視為最終定案。
- 尚未實施或尚未確認的內容，不呈現為既有成效。
- Google Sheet 為資料管理主檔；本網站為教師理解與關聯瀏覽介面。
